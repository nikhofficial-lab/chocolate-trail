Operating rules

These are deliberate safety limits.

  • Cancel before dispatch. After dispatch, record a physical return and confirm whether every item is saleable before restoring stock.
  • Never subtract stock manually after a successful website order.
  • New coupons and edited coupons are paused for review.
  • A coupon code change invalidates the old code immediately; historical orders keep their recorded code and rewards.
  • Record cash, refunds and referral settlements only after they actually happen. These controls never transfer money.

Supervisor learning guide

The safe rhythm is: review → save paused → verify → activate.

🧭 Start here

Refresh, check Ordering, stock, campaign and usable coupons. If something looks stale, refresh once before changing it.

📦 Stock

Use Add for new physical stock. Use Set exact after a complete physical count. Successful website orders already subtract stock.

🧾 Orders

Never delete an order. Cancel safely so stock and coupon use reverse together. Paid rewards must be resolved first.

🎉 Campaigns

Create or edit the full draft, save it paused, review every price, then activate the schedule. Pausing never changes orders.

🎟️ Coupons

Total pool is customer discount plus reward, never above 20%. Editing pauses the code. Renaming invalidates the old code immediately.

🤝 Partners

Review the application, approve, assign a coupon, choose delivery access, then send the secure invitation.

⭐ Wishlist

Review the requested product, link, unit weight and quantity. Email the expected price, record a private note, then mark Price sent.
